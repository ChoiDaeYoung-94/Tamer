# 실물 ARM64 오프라인 UI 검증 — 2026-11-11

SM-A175N, Android17/API37, ARM64, 1080×2340, 실제 메모리 페이지4KB에서 원래 Main/Game UI를 확인했습니다. Unity6000.3.25f1의 **release 엔진 격리 시험 앱**이며 운영 앱과 계정·저장이 분리돼 있습니다.

시험 APK는 게임 소스 `08611bd49337bdd289a99fc49e66f7022a5db9bb`, SHA-256 `4bc2d5c845cf8d32f856a009a2c661dc11c965ca6c1a77ac991852b2c7f0ab1f`입니다. 검사 시 작업본은 `e4095e2`였으나, APK에 후속 상점 한글화 `a861eb1`이 포함됐다는 뜻은 아닙니다. [최신 LD 상점 검증](full-ui-ld-validation-20261111.ko.md)과 구분합니다.

## 실제 확인

사용자가 PC의 휴대폰 미러링 창에서 원격 마우스로 ‘응답하지 않음’을 직접 선택했습니다. 이후 정상 종료하고 다른 프로세스로 다시 실행했을 때 연령 화면을 거치지 않고 마을에 진입했습니다. 연령 선택과 인증을 자동 조작하거나 앱의 비공개 설정을 우회해서 읽지 않았습니다.

- 마을, 설정 열기·확인으로 닫기, 계정·개인정보 **보기**와 설정으로 돌아가기.
- 원래 조이스틱 이동, 상점 근접 진입, 장비·동료·광고 제거 탭 표시 및 닫기. 동료 목록은 상단7개까지 보였으며 하단 스크롤을 검증한 결과는 아닙니다.
- 사냥터 진입과 Game 화면, 전투 중 설정 열기·일시정지, 확인으로 재개.
- 마을 복귀 확인창과 복귀 후 체력100, 플레이어 능력치 표시·닫기.

전투 설정을 연 두 캡처의 간격은21.316988초이며 PNG SHA-256이 동일했습니다. 재개 후에는 몬스터 위치가 바뀌었습니다. 마을 복귀 전 체력10과 복귀 후100을 확인했고 마지막 골드20000·동료0, 합성 저장소 읽기4/쓰기0·진단 오류0이었습니다. 원화면24장과 검토된 UI 입력22개를 근거로 남겼으며, 선택한 원화면9장은 사용자 고정 검토 보관함에 두었습니다.

재개 직후 첫 화면 읽기는 연결 상대의 입장 검사에서 중단됐습니다. 재개 입력을 반복하지 않고 새 읽기로 실제 상태를 확보했습니다. 실패 기록을 보존했으며 잘못된 읽기를 성공으로 덮어쓰지 않았습니다. 앱·기기 오류로 집계하지 않습니다.

## 정리와 한계

시험 앱을 정상 정리하고 HOME으로 돌아갔으며, 자체 UID·기존 운영 앱을 포함한 다른5개 앱의 UID/User0·전체 Tamer 패키지 목록·합성 시험 저장·소스 원본을 대조했습니다. 미러링 자식 프로세스와 기기/SDK 실행 소유권도 실제 종료 후 반환했습니다. 기존 운영 앱을 강제 종료하거나 새로 설치·갱신·초기화하지 않았습니다.
