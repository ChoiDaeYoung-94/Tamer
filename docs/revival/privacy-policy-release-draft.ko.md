1. Classic CloudScript와 앱 연결을 검토하고 승인된 시험 타이틀에서 검증한다. 서버에서 인증된 현재 플레이어만 삭제 대상으로 삼고, 명시적인 정상 접수 응답에서만 로그아웃·해당 소유자 로컬 정리를 수행한다. 응답 유실·오류는 unknown으로 남기며 임의 재제출하지 않는다. 별도 호스트·DB를 출시 선행 조건으로 요구하지 않는다.
2. 이메일 담당자가 앱 재설치 없이 대상 계정과 소유자를 확인할 수 있는 절차를 검증한다. 닉네임·계정 ID·발신 이메일만으로 삭제하지 않는다. 확인 불가 시 그 사유와 가능한 추가 확인 방법을 안내하며, 확인되지 않은 계정을 지우지 않는다.
3. [외부 삭제 안내 초안](account-deletion-email-draft.ko.md)을 실제 처리 범위·보관 표와 대조한 뒤 공개 안내로 확정한다. 미게시 초안이나 기존 미제공 서버 페이지를 운영 삭제 URL로 등록하지 않는다. 기존 README 정책 URL·앵커를 유지한다. 앱 내 정책 버튼 구현은 [검증 기록](privacy-policy-link.ko.md)이 있으며 Android 실제 전환 검증과 구분한다.
4. 보관 표를 확정한 범위에 한해 백업·구매 증거·접수 메일 정리를 연결한다. 소유 불명 파일이나 독립 스토어 구매 권한을 일괄 삭제하지 않는다.
5. 실제 제공 버전·광고 설정에 맞춰 정책과 Data safety·앱/웹 안내를 대조하고 시행일을 정한다. CloudScript 운영 게시, 실계정 삭제, Console 제출은 이 문서 변경에 포함하지 않는다. 최종 소거 관찰기·별도 서버·새 지원 이메일을 필수 기능으로 추가하지 않는다.

## 이번 검토의 검증 범위

문서 변경만 수행했다. 소스 경로와 기존 정책 본문을 읽기 대조하고 diff를 확인했다. Unity `6000.0.81f1`, CLI `1.0.0-beta.8`, Android min24/target36 기준은 변경하지 않았다. Editor·기기·테스트·APK 빌드를 다시 실행하지 않았으며 새 APK SHA-256은 없다. 운영 endpoint, 실제 삭제, 공급자 잔존 자료의 파기, SDK 네트워크 전송·보관, 현재 Play Console 값과 공개 게시 결과는 미검증이다. 이전 검증은 각 연결 문서의 실제 커밋·결과 범위를 따른다.
