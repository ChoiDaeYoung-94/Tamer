[UI 검토안](ui-facelift-20261029.ko.md)과 현재 운영 제공 경로를 반영한 산식은 UI2~4h+운영 인트로 통합1~2h+운영 기능8~12h+심사/정상 Play 시험 제공·새 후보5~8h = **16~26시간**입니다. 하루 유효5~6h라면 약3~6작업일입니다. 필요한 계정/기기 자료 준비와 큰 새 결함 없음이 전제이며 사용자 추가 요구·인증/외부 처리·Google 심사와 출시 후 정리는 별도입니다. Play 보호/기기 제공 문제의 외부 대기를 확정 기간으로 계산하지 않습니다.

## UI 확장 이전의 인트로 추가 계획 이력

사용자가 기존 회사 인트로를 회사 Git의 Quad D 공통 인트로로 교체하는 범위를 추가했습니다. [작업 #489](https://github.com/ChoiDaeYoung-94/Tamer/issues/489)에 기존2초로고→공통3.4초영상/효과음·Login진입·실패시진행·중복재생방지·관련빌드검사와완료조건을 등록했습니다. 현재는 원본/의존성 확인과 작업등록 완료이며 구현·새빌드/업로드는 미실행입니다. 이미 서명·업로드한27은 보존하고 인트로 반영본은 새최종후보로 연결해야 합니다. [기간 산정](quad-d-intro-and-estimate-20261029.ko.md)은 인증/심사계정 준비와 하루5~6시간 작업을 가정해 제출준비16~25시간/3~5작업일, 후속정리까지19~31시간/4~7작업일과 외부심사 대기를 구분합니다. 출시·정리 계획 범위는 약2~3주이며 확정일/전체완료율이 아닙니다.

16~25시간은최종운영확인·인트로·심사접근/새후보준비의가정별작업시간이며, 사용자가계정/인증을준비하는대기와Google심사기간은별도입니다. 세부산식·전제·날짜예시는 [일정 근거](quad-d-intro-and-estimate-20261029.ko.md)를따릅니다. 미래일자작업을자동예약/재개하지않습니다.
