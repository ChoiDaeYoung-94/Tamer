## 보류·미검증을 유지할 항목

UI 최신 보완은83cfd19의 경계 가림 안내판/일시정지 차단·Capture0→1·마을 복귀와, 앞선678816c 캐릭터 선택/cold 복원 및8943a70 상점 결과 복귀입니다. 실제 노치/다른 기기 비율·launcher·운영 계정/구매 복원·새 최종 후보와 사용자 검토는 남아 있습니다. 운영 첫 실행은 정상 Play 제공 경로가 준비되지 않아 로그인 전 차단 상태입니다.

- **실제 ARM64 16KB 실행:** 환경 미보유로 미검증입니다. LD4KB/ARM 번역·정적 LOAD/배치·Play 수락은 대체 근거가 아닙니다. 사용자의 기존 결정대로 무리한 환경 확보/기기 구매를 새 필수 작업으로 추가하지 않습니다. 가능한 실제 환경이 생기면 별도 범위로 확인합니다.
- **광고5초 닫기:** 사용자 결정으로 추가 조사를 보류했습니다. 기존 rewarded 완료→buff와 영구 No Ads를 유지합니다. 이 보류를 정책 준수/심사 통과로 계산하지 않으며 실제 심사에서 다시 문제 되면 당시 사유에 맞춰 대응합니다.
- **CI/CD·App Center:** 개인용 활성화·dispatch·새 배포 서비스 이행은 보류합니다. 기존 구성 보존은 완료 범위이고 Distribution 서비스 복구/가동을 남은 필수 복구로 약속하지 않습니다.
- **반영 불명확/사용 중 브랜치·worktree:** 자동 삭제 대상이 아닙니다. 미반영 커밋/사용권 확인 후 필요한 참조만 정리하며 코드·Library·원시 증거를 삭제하지 않습니다.
