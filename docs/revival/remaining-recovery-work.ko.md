## 보류·미검증을 유지할 항목

UI 최신 보완은 `2c71efb`의 HUD/캐릭터 SafeArea 적용·facelift9/9 및 격리 Main의 적용 로그까지입니다. 이 결과를 항목8b의 실제 노치·캐릭터 선택/상점/전투 동작·사용자 검토 완료로 계산하지 않습니다.

- **실제 ARM64 16KB 실행:** 환경 미보유로 미검증입니다. LD4KB/ARM 번역·정적 LOAD/배치·Play 수락은 대체 근거가 아닙니다. 사용자의 기존 결정대로 무리한 환경 확보/기기 구매를 새 필수 작업으로 추가하지 않습니다. 가능한 실제 환경이 생기면 별도 범위로 확인합니다.
- **광고5초 닫기:** 사용자 결정으로 추가 조사를 보류했습니다. 기존 rewarded 완료→buff와 영구 No Ads를 유지합니다. 이 보류를 정책 준수/심사 통과로 계산하지 않으며 실제 심사에서 다시 문제 되면 당시 사유에 맞춰 대응합니다.
- **CI/CD·App Center:** 개인용 활성화·dispatch·새 배포 서비스 이행은 보류합니다. 기존 구성 보존은 완료 범위이고 Distribution 서비스 복구/가동을 남은 필수 복구로 약속하지 않습니다.
- **반영 불명확/사용 중 브랜치·worktree:** 자동 삭제 대상이 아닙니다. 미반영 커밋/사용권 확인 후 필요한 참조만 정리하며 코드·Library·원시 증거를 삭제하지 않습니다.

[작업 #489](https://github.com/ChoiDaeYoung-94/Tamer/issues/489)에 기존2초로고→공통3.4초영상/효과음·Login진입·실패시진행·중복재생방지·관련빌드검사와완료조건을 등록했습니다. 현재는 원본/의존성 확인과 작업등록 완료이며 구현·새빌드/업로드는 미실행입니다. 이미 서명·업로드한27은 보존하고 인트로 반영본은 새최종후보로 연결해야 합니다. 16~25시간은최종운영확인·인트로·심사접근/새후보준비의가정별작업시간이며, 사용자가계정/인증을준비하는대기와Google심사기간은별도입니다. 세부산식·전제·날짜예시는 [일정 근거](quad-d-intro-and-estimate-20261029.ko.md)를따릅니다. 미래일자작업을자동예약/재개하지않습니다.
