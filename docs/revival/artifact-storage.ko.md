앞으로 전달할 자료와 현재 경로 안내는 이 보관함에 둡니다. 브라우저 기본 다운로드 설정은 바꾸지 않습니다. 다운로드 파일은 처리 완료 뒤 옮기며 진행 중 서명/업로드·입력 동결 자료의 경로를 중간에 바꾸지 않습니다.

정리 전 소유 작업·파일 목록·SHA와 보존할 원본을 확인합니다. 이동 뒤 모든 파일을 대조하고 최신 인계의 현재 경로를 갱신합니다. 과거 실행 로그의 당시 경로를 일괄 치환하지 않습니다. 중복/교체된 사본만 휴지통으로 보내고 실제 처리·보존 원본·복원 위치를 비공개 기록에 남깁니다. 영구 삭제나 휴지통 비우기는 기본 정리 방식이 아닙니다.

운영 계정/저장/No Ads·원키/비밀값·비공개 원본·Library·다른 프로젝트는 정리 대상에 포함하지 않습니다. 비공개 에셋 스냅샷과 기존 암호화 키 백업은 각 보호 위치를 유지하고 Drive 백업 목록에서 역할을 구분합니다. 실제 업로드/공유가 완료되지 않았다면 완료로 기록하지 않습니다.
