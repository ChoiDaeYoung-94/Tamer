# PlayFab Console 읽기 관측

2026-09-11 06:27–06:31 UTC, 기존 Chrome 로그인 세션의 Tamer 타이틀 설정에서 개인정보 담당이 읽기 전용으로 확인했다. 이 기록은 Console의 표시 상태이며 실제 로그인 응답·트래픽·개별 데이터 보관 내용의 검증이 아니다.

| 설정·화면 | 관측 |
| --- | --- |
| 집중 시간 보고 | 켜짐 |
| 장치 정보 보고 | 켜짐 |
| 전체 사용자 IP 주소 저장 | 켜짐 |
| 새 데이터 컬렉션 기능 자동 실행 | 켜짐 |
| `AllowServerToDeleteUsers` | 꺼짐 |
| Custom/Android 플레이어 생성 비활성화 | 꺼짐 |
| `RequireCustomDataJSONFormat` | 꺼짐 |
| API 액세스 정책 개요 | Client/Server/Admin 허용 표시; 인증 생략이나 개별 API 실행 성공을 의미하지 않음 |
| 이벤트 구성 | PlayStream/Telemetry routing UI 확인; 보관기간은 확인하지 못함 |
| 추가 콘텐츠 | Google 플랫폼 목록 존재; 상세 자격 증명 화면 미진입, 영수증 검증 연결 여부 미확인 |

서버 수집 설정을 전부 미확인으로 남기는 대신 위 활성 상태를 데이터 보안 검토에 반영한다. SDK의 로그인 응답 플래그와 실제 추가 장치·집중 시간 전송, IP의 실제 보관기간·목적·계약은 계속 미확인이다. `AllowServerToDeleteUsers`가 꺼져 있다는 사실만으로 모든 삭제 수단이 불가능하다고 단정하지 않으며, 현재 앱의 삭제 서비스가 구현됐다는 근거도 아니다.

설정 변경·저장·삭제·API 실행·새 로그인은 수행하지 않았다. 비밀키, 개별 회원 및 원시 이벤트는 조회하지 않았고 API 액세스 정책 화면에는 보류 중인 변경이 없음으로 표시됐다. 공개 Data safety 답안·개인정보처리방침 확정은 [후보 답안](data-safety-draft.ko.md)의 미확인 사항을 해소한 후 별도로 진행한다.
