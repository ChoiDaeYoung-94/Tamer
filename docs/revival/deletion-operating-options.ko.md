# 삭제 운영 결정 권장안과 대안

> 2026-09-22 최신 결정: 앱 내 자동 삭제는 기존 PlayFab Classic CloudScript, 앱 외부 요청은 승인된 `doeud1410@gmail.com` 이메일 접수로 단순화한다. 아래 별도 서버·DB·호스팅 대안과 과거 수동/자동 비교는 검토 이력이며 현재 필수 작업이 아니다. 앱 내 자동 삭제를 이메일로 대체하는 결정도 아니다. 별도 서버 배포·활성화는 승인되지 않았다. 최신 안내는 [출시 정책 초안](privacy-policy-release-draft.ko.md)과 [외부 이메일 안내 초안](account-deletion-email-draft.ko.md)을 따른다.

2026-09-21 최종 사용자 범위 갱신: **정상 삭제 API 접수 안내 후 로그아웃·소유 확인된 해당 계정 로컬 정리로 흐름을 종료**한다. 실제 소거 완료라고 표시하지 않는다. 완료 observer/완료 통지/지원 문의/완료 대기 worker는 필수 작업에서 제외한다. 아래 이전 완료 증거·삭제 후 조회·완료 후 재가입 조건은 과거 강한 보장 검토 이력이며 현재 출시 필수 조건이 아니다. unknown은 접수 성공으로 표시하거나 로컬 데이터를 정리하지 않고 중복 재제출을 막는다. 정상 접수 뒤 완료 증거 부재만으로 재가입을 영구 차단하지 않는다. Google/master 계정·owner 없는 legacy·독립 스토어 권한 증거는 정리하지 않는다. 현재 연결 산출물과 미검증 범위는 [접수 전용 연결 묶음](../../server/privacy/deployment/README.ko.md)을 따른다.

2026-09-21 결정 갱신: 사용자가 **자동 삭제** 방식을 명시적으로 선택했다. 아래 수동 이메일 운영 대안은 과거 검토 이력이며 재선택을 요구하지 않는다. [타이틀 전용 어댑터와 합성 검증](automatic-title-deletion.ko.md)을 진행했고, 실제 재인증·삭제 후 상태 조회·공급자 완료 확인·운영 배포는 아직 연결되지 않았다. 보관기간을 임의로 확정하지 않는다.

2026-09-14. 현재 합성 core/UI/HTTP 구현을 운영에 연결하기 위한 **검토안**이며 승인된 정책·게시 문구가 아니다. 기존 정책 본문과 URL은 유지한다. 기존 76개 타이틀 계정 정리는 이미 별도 승인으로 실행됐으므로 다시 결정하거나 삭제할 대상이 아니다.

추천 순서는 접수 책임자와 범위 확정 → 보관 대장/예외 승인 → 비운영 인증·provider 연결 → 실패·재시작·다기기 시험 → 실제 작동 문구와 URL 검토 → 게시·운영 활성화다. 지금의 `UnavailableDeletionGateway`를 완료된 운영 서비스로 표시하지 않는다. SQLite `Policy`의 보관·재가입 승인 플래그는 승인 기록을 대신하지 않으며, 앱 로컬 파일 정리도 별도 구현·검증이 필요하다.

[Google Play 계정 삭제 안내](https://support.google.com/googleplay/android-developer/answer/13327111?hl=en)를 2026-09-14 확인했다. 앱 안팎의 접수 경로와 관련 데이터 처리, 보관 예외 고지, 실제 처리 안내가 필요하며 외부 접수는 앱 재설치를 요구하지 않아야 한다. 위 운영 목표 숫자는 Google이 정한 기한이 아니라 선택을 돕기 위한 제안이다.

미정 결정을 코드 기본값·정책 문구·스토어 신고에 반영하거나 실제 운영 서비스에 게시하지 않았다. 기존 [실행 준비와 D1–D8](privacy-execution-readiness.ko.md), [합성 삭제 구현](account-deletion-test-flow.ko.md)의 경계를 유지한다.
