## 표시와 관련 회귀 검사

Unity6000.3.25f1, Android min25/target36 기준 checkout에서 원래 View와 한글 글꼴을 사용했다. 별도 비활성 PreviewScene에서 View를 구성하고 행동 컴포넌트를 제거한 뒤 표시만 렌더했다. 실제 인증·나이 입력·서버 계정 생성·게임 저장은 실행하지 않았다.

- 1080×1920·1080×2316·1080×1440 각각 첫 선택/원래 Google 실패 문구, 총6개 화면이 통과했다.
- 제목·본문·오류·버튼의 글리프/줄 넘침/화면 범위, 동일한 버튼 표시·상호작용 가능 상태, 각 버튼 중심의 최상위 raycast를 확인했다. 실제 버튼 영역은 약907.2×148pixel이었다.
- 본문은10줄로 표시됐고 실제 밝은 본문 픽셀은 각 화면36,497~36,506개였다. 빈 화면과 폰트 누락 경고는0이며6장 모두 육안으로도 확인했다. 이것을 실제 기기의 dp나 접근성 인증으로 확대하지 않는다.
- Unity CLI1.0.0-beta.8의 표준 EditMode NUnit으로 기존 `RevivalGuestEntryViewTests`만 실행했다. **2/2 Passed, Failed/Skipped/Inconclusive0**이며, 기존 한글 글꼴 참조 및 동일 선택/소유 리스너 재결속/오류 문구 표시를 확인했다. 테스트의 콜백은 가짜 카운터이며 실제 로그인 호출이 아니다.
- 전체 Revival1,094개 검사를 변경 없이 반복하거나 이번2개와 고유 검사 수로 합산하지 않았다.
