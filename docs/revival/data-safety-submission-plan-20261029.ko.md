## PlayFab의 공유 예외를 뒷받침하는 범위

10월29일 읽은 [PlayFab 공식 약관](https://developer.microsoft.com/en-us/games/products/playfab/terms/)의4.3·5.1은 Game Data의 서비스 제공 목적과 개발자 지시에 따른 개인정보 처리를 설명하고,5.6은 하위 처리자의 목적 제한을 둡니다. 이 계약상 범위와 현재 계정·진행 저장 경로를 연결하면 개발자를 대신한 처리의 공유 예외를 판단할 근거가 됩니다. **공급자가 외부 업체라는 이유만으로 이 경로 전부를 공유 Yes로 할 필요는 없습니다.**

이는 해당 경로에 대한 기술적 적용 판단이며, 앱 전체의 공유 No 결론은 아닙니다. AdMob의 공개된 공유·다른 SDK의 독립 목적은 별도로 합산합니다. Microsoft가 자체 고객 계정의 controller로 처리하는 범위까지 게임 데이터 처리자 예외로 확대하지 않습니다. 약관4.3의 기능 개선 설명도 개인정보를 제외하는 조건이 있으므로 개인 계정/진행의 별도 목적 허용으로 바꾸지 않습니다. 새 약관 수락·계약 변경·서비스 설정 변경은 하지 않았습니다.

Unity의 역할별 요청은 [IAP 안내](https://docs.unity.com/en-us/iap/privacy-and-consent/overview)에 따라 개발자 확인·지시 경로와 이용자의 독립 목적 요청 경로를 구분합니다. 기존 운영자 문의 처리14일 목표를 공급자 전체 자료 소거 기한으로 확대하지 않습니다.
