# GMA 11.6 / Android 25.5 갱신 검증 — 2026-10-26

## 변경 범위

Google Mobile Ads Unity **11.5.0 → 11.6.0**, Standard Android **25.4.0 → 25.5.0**으로 갱신했습니다. 공식 11.6.0은 2026-10-13 출시이며 [Unity 릴리스](https://github.com/googleads/googleads-mobile-unity/releases/tag/v11.6.0), [Android 릴리스 노트](https://developers.google.com/admob/android/rel-notes)를 대조했습니다. Next-Gen SDK나 PiP 기능을 새로 켜지 않았습니다. 이 갱신을 광고 5초 닫기·Families 심사 통과로 계산하지 않습니다.

- 공식 unitypackage: 1,905,990 bytes, SHA-256 `e42c4af9284a6efa3e925ecb58047b722e07c12ac28dceb4547bb743f3db4763`.
- 공식 tag source: `8ea7b043986dd7221b001023c85d569fff810666`. 기존 에셋 GUID/importer·custom manifest를 보존하고 새 에셋에는 공식 GUID를 사용했습니다. 줄끝만 바뀐 파일을 불필요하게 반영하지 않았습니다.
- 신규 EDM 자동 UPM 설치기는 최초 import 전에 `enableExternalDependencyManager: 0`으로 끕니다. 기존 legacy EDM 1.2.189와 UPM manifest/lock을 유지하며 Configure/Validate와 실제 로드된 설정 검사로 opt-out을 확인합니다. 자동 EDM 2.1 전환은 하지 않습니다.
- UMP **4.0.0**, 기존 구매/Play Games SDK·계정·저장·No Ads 동작은 변경하지 않습니다. 실제 debug runtime graph에는 Ads/Ads API25.5.0, UMP4.0.0, Billing9.0.0, Games v2 22.0.0이 선택됐습니다. PGS 의존성 제거를 주장하지 않습니다.
- `BuildSampleIsolated`는 별도 development sample APK에서 PlayGamesInitProvider와 games.APP_ID의 자동 초기화만 격리합니다. 정확한 flag 조합·sample package·Google sample App ID로 제한하며 기존 private Build의8개 bool signature를 유지합니다. 운영 publisher·연령/지역 승인·구매/로그인을 열지 않습니다.

## 로그 진단과 자료 보존

실행 후 `GoogleMobileAdsNative.Common`의 `FileNotFoundException` 진단이 발견돼 공식 소스까지 추적했습니다. 이는 기본 Android SDK 누락이 아니라 선택형 Native Ads 플러그인의 버전을 탐색하는 reflection입니다. [공식11.6 초기화 callback 코드](https://github.com/googleads/googleads-mobile-unity/blob/8ea7b043986dd7221b001023c85d569fff810666/source/plugin/Assets/GoogleMobileAds/Platforms/Android/MobileAdsClient.cs#L173-L196)는 먼저 초기화 callback을 전달하고 이 탐색 예외를 catch/ReportTrappedException으로 처리합니다. 공식11.5의 같은 블록과 동일함을 대조했습니다. 진단이 없었다고 기록하거나 숨기기 위해 선택형 플러그인·SDK 보고 설정을 변경하지 않았습니다. 실제 init/load/show/보상·종료는 성공했고 관측한 app process에서 unhandled AndroidJavaException/치명 종료는 없었습니다.

ADB 최초 offline은 정확한 대상 transport만 재연결하고 indexed serial을 다시 대조해 복구했습니다. 첫 스냅샷 helper는 Android14의 `dumpsys window windows`에 focus 필드가 없어 입력 전에 중단됐으며 읽기 명령을 `dumpsys window`로 수정했습니다. 앱 초기화 실패·광고 재시도·데이터 초기화로 계산하지 않습니다.

기존 privacy-cold 앱의 files/shared_prefs 원바이트 digest와 원래 Tamer 시험 package 목록은 전후 동일했습니다. 신규 sample만 추가·실행·종료했고 기존 앱 제거/clear/downgrade·다른 LD 인스턴스 조작·신규 결제/구매 복원·운영 계정 API·개인 폰 사용은 없었습니다. 영상은 광고 열림/표시, 별도 스크린샷·tap receipt·callback은 X 닫기와 종료 확인용입니다. 늦게 누른 close callback 시각을 SDK의 강제 대기 시간으로 해석하거나5초 X 보장 측정으로 사용하지 않습니다.
