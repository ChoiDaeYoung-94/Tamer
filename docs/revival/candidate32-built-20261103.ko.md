## 실제 변경 검토와 실패 보존

기존9개 원본에 `mainTemplate.gradle`의 x86_64 제외1줄 제거가 더해져10개를 복구했습니다. resolver XML은 기존 bundleId 변경 외에 `androidAbis`가 두 ABI로 바뀌었습니다. 처음 검토는 이 두 번째 값을 예상하지 않아 **복구 적용 전에** 중단됐고, 정확한 두 값만 정규화한 XML 전체 일치·Gradle1줄·alias/서식 변경·소유9개를 확인한 뒤 기존7필드 복구 계약으로 적용했습니다. 다른 late writer는0입니다.

승인 리소스의 처음 추가 탐색은 `.assets` 확장자만 검사해 일치하지 않았습니다. 이미 검토된 TextAsset 이름/길이/원문 framing과 bounded Data 멤버 탐색을 재사용해 정확한1개 일치를 확인했습니다. 이전 실패와 보충 기록은 비공개 보존했고 성공으로 바꾸지 않았습니다. 키/빌드는 재실행하지 않았습니다.

빌드가 생성한 임시 Gradle의 암호2필드는 종료 후 값 출력/증거 복사 없이 비웠습니다. 원키·AAB·Library 전체는 변경/삭제하지 않았습니다. 이번 후보32의 암호를 채팅에서 읽거나 입력하지 않았습니다. 이전 후보31의 별도 비밀값 노출 사고와 이번 정리 작업을 혼동하지 않습니다.
