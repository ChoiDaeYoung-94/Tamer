3. 검증된 대상 게임 계정만 권한 있는 운영 경로로 처리한다. 접수·처리에 필요한 최소 상태만 접근 제한하고, 완료 후 별도 보관용 계정·진행 데이터 사본을 만들지 않는다. 메일 수신 자체, 요청 전달, 공급자 API의 접수 응답을 최종 소거 완료로 기록하지 않는다. Google/master 계정·다른 게임·소유 불명 데이터로 범위를 확대하지 않는다.
4. 관련 자체 저장 데이터와 처리자 데이터의 삭제·보관 범위를 적용하고, 확인된 처리 상태·남는 항목·추가 조치가 있으면 회신한다. 기기에 접근할 수 없는 경우 로컬 파일까지 지웠다고 안내하지 않는다. 자동 완료 통지 시스템이나 별도 웹서버를 구축할 필요는 없다.
