# LD 오프라인 Intro/Login x86_64 경로

최신 ARM64 시험 APK가 LD의 ARM 번역에서 엔진 초기화 후 멈춰, 같은 격리 앱에 명시적인 X86_64 빌드 요청을 추가합니다. 운영용 ARM64 기준과 기존 기본 요청은 유지합니다.

- `RequestX86IntroLoginBuild`만 정확한 X86_64를 선택합니다. 일반/캐릭터 프로필, 혼합 ABI·누락 define·운영 앱 ID·custom key·bundle은 허용하지 않습니다.
- 기존 debug 앱 ID, Quad D→Login→기존 게임6씬과6개 격리 define을 유지합니다. 전역 define을 추가하지 않습니다.
- 기존 exact x86_64 제외행 변환을 재사용하고 `mainTemplate.gradle`·meta·원래 아키텍처와 기존 설정을 finally에서 복구합니다. 외부 실행기도 원본을 별도로 보존합니다.
- 관련 Intro4 및 기존 손님 격리33 NUnit, 새 ordinary68/IL16와 정확한 X86_64 APK 검사를 준비합니다. 실제 실행·복구 결과가 나오기 전에는 통과로 표시하지 않습니다.

ARM64 번역 실패를 새 경로의 성공으로 바꾸지 않으며, x86_64 결과는 실제 ARM64/16KB 또는 운영 계정·저장·광고 검증을 대신하지 않습니다. 인증·나이 자동 입력과 운영 키 사용은 포함하지 않습니다.
