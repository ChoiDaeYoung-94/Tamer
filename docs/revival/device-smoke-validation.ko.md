# 실제 ARM64 기기 smoke 검증

2026-09-11, `codex/revival-device-validation` (`6a45ff8` 기반), Unity `6000.0.81f1`.
SM-N986N / Android 13 / API 33 / ARM64의 실제 `PAGE_SIZE=4096`에서 검증했다.

- 기존 통합 APK와 실제 기기 spec으로 AAB에서 생성한 두 split 모두 새 설치, 실행, Unity 네이티브 로딩, 전경 표시, 캡처, 자체 설치 앱 제거에 성공했다.
- APK는 5초, split은 10초 관측했다. 두 캡처에서 skybox, 회색 cube, Development Build 표시를 직접 확인했다. 전체 게임 플레이 검증은 아니다.
- 첫 APK 시도는 30초 후 전경 확인에 실패했다. 앱 PID와 네이티브 로딩은 확인됐고 fatal 오류는 관측되지 않았다. `onPause`가 있었으나 원인은 미확정이다. 기기 Awake/잠금 해제를 읽기 전용으로 확인한 뒤 새 설치 재시도는 성공했다. 전경 판정 조건을 완화하지 않았다.
- 신규 도구 guard 테스트 4개가 통과했다. 기존 패키지가 있으면 중단하고, 설치 시 `-r`을 사용하지 않으며, 자신이 설치한 경로와 현재 경로가 일치할 때만 제거한다. 시스템/네트워크/계정 설정과 전역 로그는 변경하지 않는다.
- 실제 16KB 기기 실행, 구매/복원, 운영 로그인, 광고, 스토어 배포는 이 결과에 포함하지 않는다. 기존 정적 LOAD/ZIP 성공과 RELRO 미충족 판정도 그대로 유지한다.

정확한 artifact 해시와 각 빌드 코드 커밋은 `device-smoke-validation.json`에 기록했다. APK와 AAB는 서로 다른 이전 빌드이며 최신 main 재빌드로 표현하지 않는다. 원시 로그·기기 식별자·maps·스크린샷·서명 자료는 비공개 ignored 경로에만 보관한다. 검증 후 기기 슬롯을 광고 담당에게 인계했다.
