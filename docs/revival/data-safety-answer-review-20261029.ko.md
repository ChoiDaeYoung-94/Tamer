상위 답안은 수집/공유·전송 암호화 예, OAuth+기타, 기타 설명은 사용자가 명시적으로 선택하는 기기 또는 사용자 지정 식별자 기반 게임 계정, 기존 공개 계정 삭제 URL, 계정을 유지한 일부/전체 삭제 아니요입니다. 외부 계정 분기는 미적용입니다. 가족 정책 약속의 기존 Yes는 새 심사 통과가 아닙니다. 모든 전송 암호화는 정상 source/config·각 SDK 공식 안내를 적용한 권장 답안이며 전체 실제 패킷 측정이 아닙니다.

실제 미리보기에는 계정 삭제 URL과 함께 **“개발자가 데이터 삭제 요청 방법을 제공하지 않음”** 문구도 표시됐습니다. 계정 유지 삭제 문항의 아니요에 따른 표시를 숨기지 않고 사용자에게 화면으로 제시했습니다. 이를 전체 계정 삭제 경로가 없다는 뜻이나 신고 오류가 해결됐다는 뜻으로 바꾸지 않습니다.
