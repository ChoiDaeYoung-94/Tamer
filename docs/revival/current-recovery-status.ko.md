## 다음 작업과 우선순위

1. **운영 자료를 확인합니다.** 사용자 휴대폰 왕복 사진은 접수했으므로 반복 요청하지 않습니다. 운영 Console의 전체 버전·활성 인증서부터 읽기 대조하고, 이어 AdMob 메시지·지역 검토·Data Safety/공개 방침을 확인합니다. 기존 제품 결정을 다시 묻거나 승인 resource를 임의 활성화하지 않습니다.
2. **고정된 운영 후보를 만듭니다.** 위 자료와 소스·키·승인 범위를 묶어 서명 AAB를 준비하고 실제 manifest/서명/버전/네이티브 검사·복구 결과를 연결합니다. 파일이 준비되기 전에 업로드를 요청하지 않습니다.
3. **필요한 기기와 실제 제공물을 확인합니다.** 사용자 수동 업로드 이후 같은 AAB에서 나온 APK/split·앱서명·필요 기능/정책 결과를 연결합니다. 개인 폰·비밀 입력이 필요한 시점에는 준비된 대상을 안내합니다. 실제16KB 환경은 미확인이며 LD4KB·정적 검사로 대체하지 않습니다.
4. **출시 확인 뒤 정리합니다.** 시험 PlayFab/Play 앱·불필요 branch 등은 보존 필요성과 실제 소유권을 확인해 정리하고 최종 변경 요약·README 링크·저장소 소문자 이름 전환을 마칩니다. 지금 필요한 시험 자원을 먼저 삭제하지 않습니다.

## 유지할 결정과 현재 사용자 조치

9세 이상 성인 포함, 기존 AdMob 보상 광고→buff/영구 No Ads, PlayFab, 기기에 저장한 연령 선택을 유지합니다. 소유 미확인 옛 도감·장비·아이템 원본은 보존하고 현재 계정은 빈 상태로 시작합니다. No Ads/서버 저장은 이 처리 대상이 아닙니다.

삭제 문의는 기존 메일로 운영자가2주 이내 직접 처리하며 별도 삭제 서버·불필요한 자체 보관을 추가하지 않습니다. 5초 닫기 추가 조사는 사용자 결정으로 보류했고 정책 통과 근거로 계산하지 않습니다. 동일 시험2회 실패 후 재승인 규칙은 제거됐으며 원인·변경 조건·실패 이력을 남기는 현재 AGENTS를 따릅니다.

**사용자 할 일:** 현재 휴대폰 Main/왕복 반복이나 신규 결제는 필요하지 않습니다. 운영 자료는 가능한 읽기 확인을 진행하고 부족한 입력만 마무리에 모읍니다. 실제 비밀 입력·수동 업로드는 준비된 파일/대상을 안내한 뒤 진행합니다. 재확인할 제품 결정 질문은 없습니다. 10월26일 작업은22시까지이며 기본 사용률85% 보호 기준을 적용합니다. 10월24일의90% 당일 예외를 오늘 기준으로 자동 연장하지 않습니다.
