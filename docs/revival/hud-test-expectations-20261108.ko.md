# 한글 HUD의 기존 검증 기대값

HUD를 한글로 바꾼 뒤 격리 시험기와 기존 Editor 테스트가 예전 `Gold - …`, `NickName - …`와 영문 능력치 문구를 기대하고 있었다. 이 상태는 정상 HUD를 실패로 판정할 수 있다.

게임플레이/삭제 격리 시험기의 표시 비교3곳과 기존 복원/직접 장비 테스트의 기대 문구를 현재 표기에 맞춘다. 숫자·데이터 키·필드 이름과 시험기/제품의 실제 기능 흐름은 유지한다. 테스트의 능력치 키는 `Power`/`AttackSpeed`/`MoveSpeed`로 보존하고 표시 캡션만 대응한다.

4개 파일을 기준 커밋과 대조해 표시 기대값 외 변경이 없음을 확인했다. 기존 테스트2개 파일은 고정 Unity 참조285개로 사전 컴파일 종료0이다. 첫 통합 사전 컴파일의 XML 참조 누락과 서로 다른 컴파일 기호의 캐시 Player 참조 실패는 보존하고, 독립 사전 검사 범위를 테스트2파일로 바로잡았다. 실제 전체 Editor 컴파일을 대신하지 않는다.

관련 기존 테스트의 실제 실행과 새 APK 컴파일은 다음 독립 실행 범위이며 이전 ordinary68의 전체 소스 일치로 표현하지 않는다. 운영 계정/저장/구매/나이 입력과 운영 삭제는 사용하지 않는다.

후속 실제 검증(source `ecc4ed103a7dec515121c6ae8d7e81d28308575d`): 복원 값 두 경우와 직접 장비 갱신의 기존 동기 테스트 메서드3경우를 비활성 fixture에서 직접 실행해 통과했고 소유 singleton을 복구했다. 표준 NUnit 러너 전체 실행은 아니다. 새 일반 Android68 어셈블리 컴파일과 운영 IL10항목(한글/저장 키/격리 시험기·임시 Editor 진입점 제외)도 통과했다.

동일 소스로 ARM64 격리 APK를1회 생성했다. debug 인증서·별도 앱ID·min25/target36·ARM64·오프라인 권한/provider·백업 전송 제외18개·영상/시작 색상/네이티브 정렬 검사를 통과했다. APK는109,686,406bytes/SHA `a1c0b17be5e11b22669366bb4a88f4159a651f8dfe267751260b888b04044eea`이며 사용자 고정 보관함의 `02_현재검토/현재-오프라인-APK`에 있다. 이전 APK/안내는 파일 전체 SHA를 대조해 과거 보관함으로 옮겼다.

첫 제어기의 전체 실패/종료1은 보존한다. 새 컴파일 중 Bee가 이전 관리 출력137개를 정리했고, 제어기가 옛 ordinary DLL을 후속 재검사하다 실패했다. 원시 로그에 해당 삭제가 기록돼 있으며 이전 DLL은 캐시에서 같은 SHA로 복구되지 않았다. 소스/키/원본7525파일과 기존 JSON·로그·이미지는 보존했다. 새 컴파일136파일은 Unity 관리 폴더 밖으로 별도 보존하고, 같은 APK를 추가 빌드 없이 후속 읽기/패키지/IL 검사했다. Editor/build 종료0, 자기 컴파일러 정상 종료/Job active0/Dispose, 원본·임시 설정·공유 서버 실제 반환을 확인했다. 후속 artifactGate 통과를 원래 전체 실행 성공으로 바꾸지 않는다.

실물 첫 시도는 Android `dumpsys`의 설치 상태행과 별도 `User 0:` 제목을 모두 선택한 파서 결함으로 설치 전에 중단됐다. 앱 설치·시작·촬영0, 인증·나이/데이터 초기화0이며 원래 실패를 보존했다. 읽기 후속 복구에서 정확한 설치 상태행의 전후 일치와 자기 시험 앱/PID·스레드 부재를 확인해 원창 안에서 실제 반환했다. 순수 파서6경계를 보완했다. 후속 업데이트는 설치 SHA/UID/dataDir/첫 설치 시각을 유지했으나 시작 전 연결 검증에서 중단됐다. 이 실패들은 이후 성공과 구분해 보존한다.

11월8일 후속 실물 실행은 SM-N986N / Android13(API33) / ARM64 / 4096-byte 페이지에서 통과했다. 같은 APK를 재설치하지 않고 자연 인트로 완료와 Main/로그인 도착을 관측했으며, 실제 화면은 연령 확인 모달 앞에서 입력 없이 멈췄다. 원래 로그의 Ellipsis 경고는0이고, 인증·나이 제출·데이터 초기화·운영 앱 변경은0이다. 시험 앱·촬영 프로세스와 스레드 종료, 원래 운영 앱의 설치 상태 보존 및 자원 반환을 확인했다.

35초 보존 영상1,827프레임을 분석했다. 각 RGB245 이상 영역이 화면95%를 넘는 프레임과 중앙 세로띠95%를 넘는 프레임은 각각0장이었다. 시각 검토에서도 어두운 준비 화면 뒤 Quad D 로고·타이틀·연령 화면이 나타났다. 로고 전 약2초의 어두운 구간은 남으며, 영상에는 실행 전 HOME 구간도 있어 미디어 시각을 정확한 OS 실행 시각으로 해석하지 않는다. 청취·다른 기기·실제16KB와 실제 운영 계정/서버 저장/No Ads·광고 경로는 미검증이다.
