# 전체 복구 실행 목록

사용자는 리팩토링뿐 아니라 남은 복구 작업 전체의 진행을 요청했다. 이 목록의 완료는 코드 PR 수나 빌드 성공만으로 판정하지 않는다. Unity 6000.0.81f1 유지/6.3 설치 보류, CI·App Center 구성 보존/비활성은 명시된 제약이다.

| 작업 | 현재 실행·소유 | 완료에 필요한 실제 근거 |
| --- | --- | --- |
| 자체 C# 전체 감사·리팩토링 | 통합: gameplay/전체 목록, 서비스 담당: Managers/Data/Server, UI 담당: UI/Popup/Scene | 파일별 책임·의존성·판단·회귀 범위, 실제 수정 PR·의미 있는 검사·미수정 이유 |
| Families 광고·consent | UI 수명 수정 뒤 광고 담당 계속 | 정확한 native 첫 화면/닫기 시점, 지역·연령·동의·운영 설정의 구체안 및 실제 검증 |
| Data safety·개인정보처리방침·계정 삭제/보관 | 서비스 수명 수정 뒤 개인정보 담당 계속 | 현재 Console 수집 설정과 실제 처리 대조, 삭제 서비스/소유권 확인/보관 범위·기간 결정 및 구현 |
| 테스트 로그인·진행도·구매 복원·서버 영수증 | SDK 담당 서버 검증·mock 경로 준비 | 인증된 테스트 환경, 영수증 진위·재사용 방지·내구성 지급/confirm, 기존 No Ads 호환성 |
| 기존 Public→Private | 오프라인 audit/preflight/postflight 준비 완료 | 대상·백업·모든 쓰기 주체·동시성 통제, 제한 시험 후 승인된 실제 이행·재조회 |
| 업로드 키 reset | 보안 담당 구체안 준비 완료, 소유자 결정 대기 | 안전한 암호화 보관/비밀번호·off-PC 경로, 새 키·공개 PEM 신청 승인, 활성 통지·빌드검증 |
| 실제 16KB 실행 | 4KB ARM64 smoke 완료; 16KB 환경 미확보 | 실제 PAGE_SIZE=16384·프로세스 ABI·호환 모드·APK/split 실행. 정적 RELRO 실패와 구분 |
| 최종 출시 AAB·내부 테스트·신고·심사 | 위 기능·정책·서명 준비 뒤 진행 | 구체적 제출 후보와 변경 신고, 승인된 업로드/트랙/제출 및 실제 심사 결과 |

정책 선택·로그인·키 회전·운영 이행·스토어 제출은 해당 단계에 진입할 때 검토 가능한 초안과 영향을 먼저 완성하고 필요한 정보·승인을 요청한다. 대기 중에도 독립적인 구현·검증은 계속한다. 리팩토링 PR 종료를 전체 복구 종료로 표현하지 않는다.
