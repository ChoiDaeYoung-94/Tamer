# 보상형 광고의 5초 닫기 검증 경로

Google Play가 지적한 버전 26의 광고는 게임을 방해하며 5초 뒤에도 닫을 수 없었다.
현 앱 코드에는 광고 화면의 X 표시 시간을 정하는 API나 5초 종료 타이머가 없다.
SDK 11.5.0의 보상형 `Destroy()`는 표시 중인 네이티브 화면의 X를 강제로 제공하는 방법이 아니다.
따라서 이 변경은 5초 준수 판정을 만들지 않고, 격리 샘플을 실제로 요청해 측정할 수 있게 한다.

## 격리 샘플만 여는 변경

기존 `RevivalAdHarnessBuild.BuildSample`은 Google 공식 샘플 App ID와 보상형 단위,
별도 Android 패키지 `com.AeDeong.MonsterTamer.revival.ads`, debug 서명을 사용한다.
이 빌드에만 `TAMER_AD_SAMPLE_CLOSE_HARNESS`를 추가했다. 런타임은 패키지·개발 빌드·
기존 격리 씬·`Managers` 부재를 모두 검사한다. Editor는 추적 중인 게시자 App ID를
사용할 수 있어 네트워크 샘플 요청을 허용하지 않는다. 배치/일반 앱/릴리스 대조
빌드도 이 허용 경로에 들어갈 수 없다.

화면에서 **합성 연령**, UMP 테스트 지리, 테스트 기기 해시 32자리 hex를 입력하고
`Load sample`을 명시적으로 누른 뒤에만 UMP Update → 필요한 폼 → SDK 초기화 →
샘플 광고 로드가 진행된다. 연령 미상·응답 거부와 잘못된 해시는 요청 전에 차단된다.
선택값은 기기 저장이나 로그에 남기지 않으며 첫 로드 뒤에는 UI에서 잠긴다.
다른 연령·지역 사례로 전환할 때는 앱 정보에서 이 격리 패키지의 **앱 데이터 삭제** 후
다시 실행한다. 재시작만으로는 UMP에 남은 이전 동의 상태가 지워지지 않는다.
기존 제품의 연령 저장값이나 지역 검토 gate는 바꾸지 않는다.

`Show sample`은 기존 보상 세션·BGM·닫힘 콜백 경로를 사용한다. 이벤트 로그는
show 호출, opened 콜백, earned/closed 콜백 사이의 단조 시계 경과를 기록한다.
opened 콜백은 네이티브 첫 픽셀이나 X 표시 시점이 아니다.

## 기기 측정 판정

공유 테스트폰과 실행 슬롯이 배정되면 공식 샘플 광고 **한 회**를 우선 검증한다.
화면 녹화에서 첫 광고 픽셀, X 첫 표시, 5초 이후 X 실제 터치, 앱 복귀,
필요한 추가 확인 단계 및 보상 결과를 프레임 시각으로 각각 기록한다.
보상 미취득 조기 종료는 무보상이고 BGM과 게임 진행이 복구돼야 한다.
샘플은 계측 절차와 앱 콜백의 검증일 뿐, 운영 소재의 5초 준수 증거가 아니다.
실제 운영 소재와 두 게임 배치(10분 버프·HP 회복)는 별도로 측정해야 한다.

Google Play Families 정책은 아동 또는 연령 미상 이용자의 게임을 방해하는
rewarded/opt-in 광고도 5초 뒤 닫을 수 있어야 한다고 명시한다.
일반 전면광고 15초 규칙의 명시적 선택 보상형 예외를 여기에 적용하지 않는다.
AdMob 고참여 설정의 보상 skip 30/60초도 5초 X 보증이 아니다.
[Families 정책](https://support.google.com/googleplay/android-developer/answer/9893335?hl=en),
[일반 광고 정책](https://support.google.com/googleplay/android-developer/answer/9857753?hl=en),
[고참여 광고 설정](https://support.google.com/admob/answer/15525707?hl=en-GB).

## 출시 연결 전에 남는 조건

현재 `RegionalConsentReviewed=false`이고 비개발 릴리스에는 운영 광고 요청 경로가 없다.
허용된 경로도 공식 샘플 단위만 로드한다. 따라서 이 변경을 운영 광고 복구나
Families 위반 해결로 표시하지 않는다. 확정된 정책 URL·메시지·연령/지역 계약,
운영 단위와 공급 소재 제한, 기기 5초 실제 입력 증거가 필요하다.
그때 제품 gate와 운영 광고 단위를 별도로 검토해 연결한다.
No Ads 신규 구매·기존 권한·복원 흐름은 변경하지 않는다.
