## 실행 환경 보완

오늘 APK 생성은1회 성공했고 원본을 정확 복구했습니다. 그러나 Unity 종료 로그에 공유 ADB 서버를 종료하는 동작이 직접 남아 다른 프로젝트의 기기 보호 검사가 중단됐습니다. 새 서버를 fresh 대조한 뒤 기기 검증을 재개했으며, 서버 자동 재시작 주체는 확정하지 않았습니다.

앞으로 별도 격리가 검증되기 전에는 **Unity Editor의 시작부터 종료·잔여 자식 정리·복구까지와 모든 ADB 기기 검증을 직렬화**합니다. 명시 ADB 호출0만으로 비충돌을 판단하지 않습니다. 기존 공유 서버를 편의상 교체하지 않으며, 기기 범위에서는 PID·생성 시각·실행 파일·SHA·listener를 확인하고 신원 변경 시 다음 입력 전에 중단합니다.
