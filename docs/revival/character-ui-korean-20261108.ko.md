# 캐릭터 선택 화면 한글 표기

캐릭터 선택 화면의 영어 문구를 로그인·HUD·설정 화면과 맞췄다. 실제 계정 메뉴 생성 문구1곳을 ‘계정 및 개인정보’로 바꿨고 정확 역치환으로 다른 코드가 동일함을 확인했다. Sex/Man/Woman/Right 키, 선택·저장·계정 세대·삭제 경계와 버튼 이벤트는 보존한다.

Unity 6000.3.25f1 Editor에서 장면의 BEGIN ADVENTURE/CHOOSE YOUR TAMER를 ‘모험 시작/테이머 선택’으로 바꾸고 기존 한글 글꼴·재질을 연결했다. 문구·글꼴·재질6개와 제목색1개만 적용했으며 장면546개 블록/기존 FileID·GUID와 나머지544개 블록은 원본 그대로 보존했다.

남·여 캐릭터×1080×1440/1920/2400의 비활성 preview6개에서 한글 글리프·버튼 최상위 hit·최소44px 터치 영역 검사를 통과했고 경고는0개였다. 제목을 기존 팔레트의 짙은 녹색으로 바꾸고 각 렌더의 제목 행 배경 대표색과 대비를 계산해5.75~5.94를 확인했다. 기존 캐릭터 이동 취소 fixture1개를 직접 호출해 통과했으며 표준 NUnit runner 실행과 구분한다. 추가 시험 define 없이 일반 Android 스크립트68개 어셈블리의 새 컴파일과 IL 검사13개도 통과했다. GUID 감사135개 파일에서 미해결 참조는0개였다.

첫 preview는 시험 카메라의 Graphic depth 갱신 전에 raycast해 버튼 검사를 실패했다. render 후 검사하도록 시험만 수정했다. Idle 표본이 덮어쓴 원래 캐릭터 회전 복원과 구름 shader의 동기 사전 컴파일도 시험에만 적용했다. 실제 장면의 회전·재질·버튼 이벤트는 변경하지 않았다.

두 번째 실행의 UI·컴파일 하위 검사는 통과했지만 전체 제어기는 Unity 저장 과정에서 생긴70개 블록의 schema 변경을 거부해 실패로 보존했다. Editor 종료와 소스·설정 복구 후 별도 읽기 검토로8가지 변경 형태를 확인하고 원본에 표시 블록2개만 반영했다. 이 별도 결과를 원래 실행의 성공으로 표현하지 않는다. 생성된 관리 DLL/PDB136개는 Unity가 정리하는 출력 폴더 밖에 해시와 함께 보존했다.

후속 제목색 실행은 전체 제어기와 CLI가 모두0으로 종료했고 알려진70개 schema 변경의 원본을 보존했다. 보호 파일7,526개·설정·기존 키/JDK 복구와 잔여 Editor/자식 프로세스 부재도 확인했다. 앞선 실행의 실패 기록은 그대로 남긴다.

기존 오프라인 캐릭터 앱에 한해 상태·버튼 위치를 읽는 passive probe를 추가했다. 정확한 debug 앱 ID·합성 계정·차단된 광고를 확인하며 listener 호출·선택·저장·인증·나이 입력은 하지 않는다. 별도 사전 C# 컴파일을 통과했고 일반 운영 어셈블리에서는 제외됨을 IL로 확인했다.

기존 ecc4ed1 오프라인 APK는 이 후속 변경을 포함하지 않는다. 캐릭터 선택의 실물 조작·서버 저장·운영 계정·No Ads·나이 입력은 아직 미검증이다. 새 격리 APK와 실물 조작 검증을 이어간다.
