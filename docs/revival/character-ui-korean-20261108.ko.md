# 캐릭터 선택 화면 한글 표기

캐릭터 선택 화면의 남아 있는 영어 문구를 로그인·HUD·설정 화면과 맞춘다. 먼저 실제 계정 메뉴 생성 문구1곳을 ‘계정 및 개인정보’로 바꿨고 정확 역치환으로 다른 코드가 동일함을 확인했다. Sex/Man/Woman/Right 키, 선택·저장·계정 세대·삭제 경계와 버튼 이벤트는 보존한다.

후속 Editor 범위에서 장면의 BEGIN ADVENTURE/CHOOSE YOUR TAMER를 ‘모험 시작/테이머 선택’으로 바꾸고 기존 한글 글꼴·재질을 연결할 예정이다. 장면546개 블록/기존 FileID와 나머지 속성을 보존한다. 남·여 캐릭터 두 경우와 세 화면비의 표시·글리프·버튼 가림을 비활성 preview로 확인하며 실제 계정·선택·서버 저장·나이 입력은 하지 않는다.

현재는 계정 메뉴 문구1곳만 반영됐고 장면 수정과 Editor/Player 검증은 미실행이다. 기존 ecc4ed1 오프라인 APK는 이 후속 변경을 포함하지 않는다.
